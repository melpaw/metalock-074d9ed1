## Placement rules

- **Routes** must live under `src/routes/`. File-based routing is a
  hard requirement of TanStack Start.
- **UI primitives** go under `src/components/ui/` and are treated
  as vendored (shadcn/ui). Edits are OK but tracked separately.
- **Cross-feature components** go directly in `src/components/`;
  feature-scoped ones get a subfolder.
- **Server-only** helpers must be either `*.server.ts` or imported
  inside a server function handler body — never at module scope of
  a client-imported file.
- **Auto-generated files** (see `integrations/supabase/*`,
  `routeTree.gen.ts`, `supabase/config.toml`) must not be edited by
  hand; they are regenerated on the next Lovable/Supabase sync.
